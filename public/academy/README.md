# Public Academy Assets

## Purpose
This directory exposes the copied Goodbody Summer Academy package through the existing Flask static file server.

## Ownership and Scope
Owned by the GoodbodyBucks app. Contents here are app-served educational materials, printable files, tracker workbooks, and platform reference docs copied from the downloaded Academy package.

## Contents
- `package/` contains the copied `final_package` directory from the downloaded Academy bundle.
- `academy-data.json` is the app-facing manifest used by the Summer Academy hub in the main page.
- `README.md` and `CHANGELOG.md` document this static asset area.
