# Copied Summer Academy Package

## Purpose
This directory is the app-served copy of the downloaded Goodbody Summer Academy `final_package` bundle.

## Ownership and Scope
Owned by the GoodbodyBucks app as a static mirror of the downloaded Academy materials. Keep source curriculum files here so the current Flask app can link to them without changing the original download.

## Contents
- `0_START_HERE/` through `12_TECH_PLATFORM/` contain the copied Academy curriculum, printables, certificates, tracker workbook, GBB docs, and optional platform notes.
- PDFs, DOCX files, PPTX decks, XLSX workbook, SQL files, and Markdown docs are served read-only through `/academy/package/...`.
