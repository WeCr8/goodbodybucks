# Public Static Assets

## Purpose
This directory contains files served directly by the Flask app through `static_folder='public'`.

## Ownership and Scope
Owned by the GoodbodyBucks app. Store browser-accessible images, Academy materials, manifests, and other static files here.

## Contents
- `images/` contains app menu, wallet, consequence, learning, and food images.
- `academy/` contains the copied Summer Academy package and its app-facing manifest.
